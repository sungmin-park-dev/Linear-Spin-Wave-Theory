# Map - working-pad

LSWT 프로젝트의 진행 중 작업, 제안, 이슈, 검토 대기 문서를 보관하는 운영 작업 공간.

- 아직 정본화되지 않은 운영 지식은 이 계층에 둔다.
- 사용자 승인 또는 검토 후 durable한 절차는 `GOVERNMENT/Agents-Bylaws/`에 둔다.
- 보호해야 할 확정 원칙은 `GOVERNMENT/User-Constitution/`에 둔다.

## 목차

| 항목 | 역할 |
|---|---|
| `handoff/` | 대화/작업 세션 인수인계 문서 |
| `idea-proposals/` | 구조·철학·방향 제안 백로그 |
| `issue-notes/` | 미해결/종결 이슈와 논의 기록 |
| `vault-staging/` | 정본 승격 전 사용자 승인 대기 문서 |
| `inbox/` | 아직 분류하지 않은 임시 캡처 |
| `project-review/` | Claude 프로젝트 공유 폴더에서 옮긴 2026-10-01 검토·계획 문서 사본 (연구 작업대 자료) |
| [[GOVERNMENT/Working-Pad/roadmap\|roadmap]] | 범용 2D 스핀 solver 최종 목표까지의 단계별 로드맵 |
| [[GOVERNMENT/Working-Pad/TASK-QUEUE\|TASK-QUEUE]] | 활성 작업 큐. 새 open 항목 추가/종결 시 함께 갱신 |
| [[GOVERNMENT/Working-Pad/map-working-pad\|map-working-pad]] | 이 navigation 파일 |

### Remarks

하위 폴더 내부 문서는 각 하위 폴더의 map에서 관리한다. 활성 항목은 `TASK-QUEUE.md`와 동기화한다.

## 에이전트 지침

- 새 작업 문서는 먼저 이 계층에 둔다.
- 결론난 절차 문서는 `GOVERNMENT/Agents-Bylaws/` map과 함께 갱신한다.
- 파일 추가, 이동, 종결 처리 시 해당 하위 map 파일을 갱신한다.
- `handoff/open/`, `issue-notes/open/`, `vault-staging/`, `idea-proposals/`의 활성 항목은 `TASK-QUEUE.md`와 동기화한다.
