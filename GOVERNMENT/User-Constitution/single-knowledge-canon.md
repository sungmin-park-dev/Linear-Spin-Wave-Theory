# Single Knowledge Canon Principle

프로젝트의 한 지식 영역에는 하나의 정본 작성면만 둔다. 정본은 논리 단위별
여러 파일로 나뉜 corpus일 수 있지만, 동일한 지식을 여러 형식의 동등한 편집
master로 관리하지 않는다.

## Principles

1. 하나의 지식 항목에는 하나의 규범적 정본만 존재한다.
2. 근거 자료, draft, 코드, 테스트, 참고문헌 registry, 생성된 출판물은 정본의
   오류를 드러낼 수 있지만 스스로 지식 정본이 되지 않는다.
3. 파생 산출물에서 의미 또는 수식 오류가 발견되면 정본을 먼저 수정하고
   다시 생성한다. 파생 산출물을 독립적으로 수정해 지식 변경을 만들지 않는다.
4. 지식 승인, 코드 검증, 출판·배포 상태는 서로 독립적으로 기록한다.

## Application

각 지식 영역은 Court-Precedents 결정에서 정본 형식과 범위를 구체적으로
지정한다. LSWT 이론에는
`GOVERNMENT/Court-Precedents/2026-08-01-lswt-markdown-source-authority.md`를
적용한다.
