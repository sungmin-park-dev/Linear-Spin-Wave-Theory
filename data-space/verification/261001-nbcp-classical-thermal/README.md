# NBCP Y state: classical finite-temperature scan — 2026-10-01

Generated by `examples/nbcp_classical_thermal.py` (Monte Carlo, decision D40). Raw values are in `report.json`.

Model: classical spins of length 1/2; J = 0.075 meV, J_z = 0.125 meV, J_PD = 0.010 meV, g_z = 4.645; B = 0.2 T along c.
Tori: L × L with L = 12, 18, 24, annealed downwards from the Y state.
Sampling: 1000 thermalization sweeps and 3000 measurements every 2 sweeps (Metropolis plus overrelaxation, acceptance ≈ 0.5). T is in meV (1 K = 0.08617 meV).

## Reading

1. In the classical model the density order sets in about six times higher in T than the phase quasi-order. Between them, T_BKT < T < T_d, there is a window with density order and no phase stiffness. Below T_BKT the phase has a finite stiffness while the density order stays saturated.
2. No sixfold lock-in appears down to 0.001 meV on these sizes. This is expected: classically the J_PD orbit is flat (zero pinning at T = 0), so only thermal order by disorder could pin the angle, and it is too weak to see here. The NBCP sixfold pinning is a quantum zero-point effect, which this classical calculation does not contain.
3. The stiffness is that of the U(1)-symmetric part of the exchange. The J_PD part is left out, as D40 requires for a twist that is not U(1) symmetric.
4. Classical temperature scales for spins of length 1/2 are not the quantum S = 1/2 ones. Use the ordering (T_BKT ≪ T_d) and the absence of classical lock-in, not the absolute temperatures.
5. Only J_PD is included. With J_Γ ≠ 0 the threefold harmonic is relevant (NBCP note), so this scan says nothing about V or mixed SOC.
