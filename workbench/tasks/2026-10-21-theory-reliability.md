## 고친 것

- **D69**: 비공선 상태에서 영역 중심으로 접힌 Goldstone 모드 근처의 1/S 마그논 에너지가 두 큰 항(HF+tadpole, Re Σ₃, 각각 1/|k|)의 상쇄로 나오는데, 격자 밖 k에서는 메시 오차가 커서 경고 없이 0.4–3.3배 틀렸다(기대 1.08). 상쇄 비 ρ > N/4이면 NaN과 경고. `magnon_energies`, `spectral_function`. 잠정 승인, 비교 대상은 CZ09 식 (56).
- **D70** (사용자 승인 "그렇게하자"): `classical_search`의 기본 시드가 국소적으로 안정한 국소 최소에 갇혔다(BCAO J3 = 0.45, Jz± = 0.5, 셀 [[1,0],[0,6]]: 기본 시드 −0.30361(UUD), 다른 시드 −0.30419). 이제 기본값 `restarts="adaptive"`가 시드를 바꿔 다시 돌린다. 초격자 LT 하한에 닿으면 바로 멈추고, 아니면 연속 2번 낮아지지 않을 때(최대 8번) 멈춘다. 결과에 시드별 에너지와 하한을 적는다.

## 열린 것 (사용자 판정 필요)

1. **η = 0 메시 주값.** 띠가 두 마그논 연속체 안에 있으면 `magnon_energies(eta=0)`의 실수부가 메시에 민감하다(삼각 같은 k에서 N = 24와 48이 0.87과 1.18). 지금은 숫자를 낸다. 연속체 안이면 NaN으로 할지, 삼각형 적분 주값(`spectral_function`과 같은 방식)으로 바꿀지.
2. **Maksimov J3 = 0.45 경계.** 논문(2308.10672)은 UUD → 이중 지그재그 경계를 Jz± ≈ 0.9로 적었는데, 같은 해밀토니안에서 두 코드 모두 0.55 근처다. Jz± = 0.7에서 이중 지그재그(−0.34152)가 UUD(−0.33337)보다 낮은 변분 상태가 있으므로 논문 값을 같은 모형으로 재현할 수 없다. J3 = 0.2의 삼중 지그재그 상한 0.6과 J3 = 0.34의 이중 지그재그 시작(≈0.2)은 맞는다. 원인은 논문 쪽 계산(정규화 또는 최소화)으로 보이며 단정하지 않는다. BCAO 연구에서 이 차이를 기록하고 넘어간다.
