# Common Theory Candidates

이 디렉토리는 여러 solver가 공유할 가능성이 있는 theory convention을 검토하는
임시 candidate workspace다. 현재 사용자 승인 정본은 없다.

## Purpose

- LSWT 문서를 정리하면서 다른 solver도 공유해야 할 정의 후보를 기록한다.
- Solver별 가정과 무관한 공통 operator·notation 경계를 검토한다.
- 충분한 근거와 사용자 승인을 얻은 항목만 장기 common convention으로
  승격한다.

## Boundary

- 이 폴더의 `draft` 문서는 accepted canon, LSWT source authority 또는 code
  contract가 아니다.
- LSWT 전용 notation과 convention은 우선 `theory/lswt/`에서 검증한다.
- Source가 없거나 solver 간 의미가 아직 다르면 `Unknown`을 유지한다.
- 사용자 확인 전 기존 candidate를 확정 규칙으로 사용하거나 범위를 넓히지
  않는다.

## Current State

- Candidate draft notes: 2
- User-approved accepted canon: 0
- Scope decision: open
