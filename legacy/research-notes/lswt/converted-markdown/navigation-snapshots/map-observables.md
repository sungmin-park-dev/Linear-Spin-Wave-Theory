# Map - observables

> 이 파일은 `research-space/theory/lswt/observables/`의 인덱스입니다.
> 새 observable 문서를 추가하면 이 표도 갱신합니다.

- LSWT 대각화 결과에서 계산하는 spectrum, thermodynamics, correlations,
  response, topology 문서를 관리한다.
- 먼저 magnon observable gateway를 읽고 필요한 물리량 문서로 이동한다.

### Remarks

관측량별 normalization, band sum, 단위 문제는 상위 audit의 열린 결정과 함께
검토한다. 이 map은 해당 결정을 대신하지 않는다.

## 에이전트 지침

- Observable 식을 추가할 때 입력 eigenvalue, eigenvector, band-space convention을
  명시한다.
- 코드 모듈이 존재한다는 이유만으로 문서 검증 완료로 표시하지 않는다.
