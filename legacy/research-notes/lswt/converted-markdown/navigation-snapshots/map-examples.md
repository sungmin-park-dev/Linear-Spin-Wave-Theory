# Map - examples

> 이 파일은 `research-space/theory/lswt/examples/`의 인덱스입니다.
> 새 theory example을 추가하면 이 표도 갱신합니다.

- LSWT 유도를 한 문제에 적용하는 이론 예제를 관리한다.
- 실행 코드는 `doc-space/examples/`에 두고, 이 폴더에서는 수식 흐름과 검증
  경계를 설명한다.

### Remarks

Theory example과 실행 코드가 같은 결과를 낸다는 주장은 수치 대조가 끝난 뒤에만
기록한다.

## 에이전트 지침

- 실행 절차나 패키지 사용법은 이론 예제 본문과 섞지 않고 `doc-space/`로
  연결한다.
- 검증되지 않은 예상값을 예제 결과로 기입하지 않는다.
