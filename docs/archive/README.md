# 문서 아카이브

집필을 종료한 이전 문서나 보존할 스냅샷을 주제별로 둔다. [NBCP 전환 직전 Markdown·변환기·서식](nbcp/2026-09-18-markdown-source.zip)을 보존한다. 현재 편집 원본은 [NBCP LaTeX](../nbcp/main.tex)다. 활성 문서에서 제외할 때에는 날짜, 기존 역할과 후속 문서의 위치를 함께 기록한다.

기존 아카이브는 [legacy/research-notes/](../../legacy/research-notes/)에 그대로 보존되어 있다. 그 안의 [LSWT converted Markdown](../../legacy/research-notes/lswt/converted-markdown/)은 현재 이론 본문과 대조하는 역사 자료다.

계속 참조하는 원본 PDF와 과거 TeX 전사본은 [LSWT sources](../lswt/sources/README.md)에 있다. 오래된 자료라는 이유만으로 이곳으로 옮기지 않는다. NBCP의 재생성 가능한 PDF는 [nbcp/output/](../nbcp/output/)에서 관리한다. 병합 전 NBCP 편집 파일의 복구용 압축본은 [통합 검증 자료](../../data-space/verification/260916-nbcp-integration/)에 보존한다.
