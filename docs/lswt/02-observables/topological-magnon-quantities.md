# Topological Magnon Quantities

The proposed scope includes lattice spin-texture topology, magnon-band topology, and thermal Hall response. These quantities require distinct definitions: a skyrmion number characterizes a spin texture, whereas a magnon Chern number refers to band eigenvectors. Bosonic eigenvector normalization and response units must be specified for the band and transport quantities.

## Topics

- Lattice skyrmion number.
- Magnon Chern number.
- Magnon thermal Hall response.
